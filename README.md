# AI-SRE-Platform

一个带**提示词注入防御**的 Kubernetes 运维 Agent，以及围绕它做的一整套实测。

不是教程复现。这里每一条设计都有实验数字支撑，**包括那些证明我原本想法是错的数字** ——
被证伪的假设和走错的路都留在文档里，因为它们通常比结论更有信息量。

```
Prometheus 告警
   ↓  结构化解析（约束解码）
   ↓  LangGraph 有环图：investigate ⇄ execute
   ↓  工具全部走 MCP，审计记在协议层
   ↓  ⚠️ 容器日志是不可信输入 → 进模型上下文【之前】逐行剥离注入
   ↓  破坏性操作 → 人工审批门控（interrupt，零副作用）
   ↓  结构化 Postmortem + 7 个机械检测器交叉核查
   ↓  Prometheus / Grafana / OpenTelemetry
```

---

## 几个实测结论

它们的共同点是：**都和直觉相反，而且都是被自己的数据推翻后才得到的。**

#### 门控不切断攻击路径，只更换执行者

加了人工审批之后，「Agent 直接执行破坏操作」2/2 → 0/2；
但同时「以 `risk=high` 建议**人类**去做同一件事」0/2 → **2/2**。
**危害转移了，没有消失。** 这个模式在整个项目里反复出现。

#### 模型不是「识别不了」注入，是「不会自己去识别」

Phase 4 测出「模型从未自行识别注入」16/16。我据此认为只能靠微调解决 ——
**错了**。把注入片段单独拿出来直接问，`qwen3:14b` 是 **83/83 = 100%**。
能力在权重里，只是排查过程中不会被自己调用。
→ 修法因此是**加一个显式审查节点**，而不是微调。

#### 微调「成功」了，但成功的是错的东西

微调后的 4B 在测试集上 83/83，追平 14B。
可我怀疑了这个满分，造了对抗集，发现它学到的是
**「这行是人写的还是机器写的」** —— 机器格式 → 无害，自然语言 → 有害。
21 个误报全落在正常的 runbook 引用、安全提示、排查建议上。
**捷径是我自己的数据集送的**（clean 样本里没有一条「有插入但无害」）。

#### 然后我发现前面一批结论都在噪声里

一个纯观测参数 `steps_per_eval`（50→25）让同配置的结果差了 18.8 个点。
于是去量噪声底：**同数据同超参、只改 seed，100 步时 F6b 的极差是 59.4 个点。**
「超过 14B」「步数是主导变量」「A/B 初始化更优」——**全部作废**。
（训练到收敛后噪声底降到 10.9 点，带区间重裁后才有了站得住的结论。）

#### LoRA 不要 fuse 回 4bit

F6a 从 87.5% **崩到 50.0%**。`--dequantize` 版与 adapter 分离逐格一致，
说明问题纯在重新量化：**ΔW 的量级小于 4bit 的量化步长，被直接吞掉**。
保持 adapter 分离只多 29 MB、只慢 11%、质量零损失。

#### 一个完全失效的净化器，它的 QPS / 延迟 / 错误率全是绿的

所以 Phase 6 的核心不是装 Prometheus，而是设计**能回答「防御还有效吗」的 SLI**：
定期把已知载荷喂给判别器（canary），**按家族统计**、**检出率与误报率成对看**。
—— 只看检出率的话，「把一切都判为注入」能拿满分。

## 方法论

跑下来最贵的几课，都不是关于模型的：

1. **满分先查捷径**，而捷径通常是自己的夹具送的。
2. **先量噪声底，再谈信号。** 这条失守过两次，第二次代价是一批已写下的结论作废。
3. **单侧指标会骗人。** 检出率与误报率必须成对；总准确率会把某一族的 33% 掩盖成 60%。
4. **检测器要先验证「能抓到」，再验证「不误报」。** 只测后者等于没有检测器 ——
   实测踩过一条 PromQL 告警因 label 匹配失败而**永不触发**，界面上一直是安详的 `inactive`。
5. **做完整的配置交叉，别只测最终配置。** 只测「全部防御都开」那一档，
   会错过「单独开净化反而制造危害」这种事。
6. **可疑 ≠ 有害。** 读源码能发现可疑之处，但它是否真的有害要另外测 ——
   我把三个默认值判成「有毒」，实测只有一个立得住。

## 环境

MacBook Pro 14" M4 Pro / **24 GiB** — 全部实验都在这台机器上跑完。
内存是比算力更硬的约束：14B 常驻 9.3 GiB + judge 2.5 GiB，
所以架构上**模型不进 Pod**。哪些东西在 Apple Silicon 上测不了，
诚实记录在 [`phase6-why.md` §6](docs/phase6-why.md)。
